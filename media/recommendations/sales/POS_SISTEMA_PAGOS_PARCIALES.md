# 💰 Sistema POS con Pagos Parciales y Cortes de Caja

## 📋 Descripción General

Sistema completo de punto de venta (POS) diseñado específicamente para imprenta, con soporte para:

- **Pagos parciales** (adelantos y pagos diferidos)
- **Cortes de caja** (parciales y finales)
- **Tracking completo** de órdenes y pagos
- **Reconciliación diaria** de efectivo

---

## 🏗️ Arquitectura del Sistema

### Flujo de Operación

```
┌─────────────────────────────────────────────────────────────────┐
│                         FLUJO COMPLETO                          │
└─────────────────────────────────────────────────────────────────┘

1. EMPLEADO (Employee)
   ├─ Crea orden con detalles
   ├─ Calcula total_price (suma de subtotales)
   ├─ Aplica discount
   ├─ Calcula igv (18%)
   └─ Define final_amount = total_price - discount + igv

2. CAJERO (Cashier)
   ├─ Abre sesión de caja
   │  ├─ Registra opening_balance
   │  └─ Define session_type (PARCIAL/FINAL)
   │
   ├─ Visualiza órdenes pendientes
   │  ├─ Filtra por payment_status
   │  └─ Ordena por fecha
   │
   ├─ Registra pagos
   │  ├─ Adelanto (pago parcial)
   │  ├─ Pago final
   │  └─ Pagos de órdenes antiguas
   │
   ├─ Actualiza estados de orden
   │  ├─ EN_PRODUCCION
   │  ├─ COMPLETADO
   │  └─ ENTREGADO
   │
   └─ Cierra sesión de caja
      ├─ Corte parcial (durante el día)
      ├─ Corte final (fin del día)
      └─ Reconciliación de efectivo
```

## 🗄️ Estructura de Base de Datos

### 1. **sales.orders** (Órdenes)

```sql
CREATE TABLE sales.orders (
  id UUID PRIMARY KEY,
  shop_id UUID,
  customer_id UUID,
  employee_id UUID,
  order_number INT GENERATED BY DEFAULT AS IDENTITY,
  status_id SMALLINT DEFAULT 1,

  -- 💵 CAMPOS FINANCIEROS
  total_price NUMERIC(15,4) NOT NULL DEFAULT 0,      -- Suma de subtotales
  discount NUMERIC(15,4) DEFAULT 0,                   -- Descuento aplicado
  igv NUMERIC(15,4) DEFAULT 0,                        -- 18% de impuesto
  final_amount NUMERIC(15,4) NOT NULL DEFAULT 0,     -- Total final a pagar

  -- 💳 CONTROL DE PAGOS
  advance NUMERIC(15,4) DEFAULT 0,                    -- Total pagado
  remaining_balance NUMERIC(15,4) NOT NULL DEFAULT 0, -- Saldo pendiente
  payment_status TEXT NOT NULL DEFAULT 'PENDIENTE',   -- Estado
  fully_paid_at TIMESTAMPTZ,                          -- Fecha de pago completo

  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW(),
  deleted_at TIMESTAMPTZ
);
```

**Estados de Pago:**

- `PENDIENTE`: No se ha recibido ningún pago
- `PARCIAL`: Se ha recibido adelanto (advance > 0, remaining_balance > 0)
- `PAGADO`: Pago completado (remaining_balance = 0)

**Cálculo Automático:**

```
final_amount = total_price - discount + igv
remaining_balance = final_amount - advance
```

### 2. **sales.payments** (Registro de Pagos)

```sql
CREATE TABLE sales.payments (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  order_id UUID NOT NULL,                            -- FK a orders
  cash_register_session_id UUID,                     -- FK a sesión de caja

  -- 💰 INFORMACIÓN DEL PAGO
  amount NUMERIC(15,4) NOT NULL,
  payment_method TEXT NOT NULL,                      -- Método de pago
  payment_date TIMESTAMPTZ NOT NULL DEFAULT NOW(),

  -- 📝 METADATA
  transaction_reference TEXT,                        -- Nro. de operación
  notes TEXT,

  -- 👤 AUDITORÍA
  received_by_id UUID,                               -- Empleado que recibió
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW(),
  deleted_at TIMESTAMPTZ
);
```

**Métodos de Pago Soportados:**

- `EFECTIVO`
- `YAPE`
- `TARJETA_DEBITO`
- `TARJETA_CREDITO`
- `TRANSFERENCIA`
- `DEPOSITO`
- `DOLARES`
- `OTRO`

**Características Clave:**

- ✅ **Múltiples pagos por orden**: Una orden puede tener N pagos
- ✅ **Pagos en diferentes días**: Cada pago tiene su `payment_date`
- ✅ **Asociación a sesión de caja**: Permite tracking diario
- ✅ **Auditoría completa**: Registra quién recibió el pago

### 3. **sales.cash_register_sessions** (Sesiones de Caja)

```sql
CREATE TABLE sales.cash_register_sessions (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  shop_id UUID NOT NULL,
  cashier_id UUID NOT NULL,

  -- 🎯 CONTROL DE SESIÓN
  session_number INT GENERATED BY DEFAULT AS IDENTITY,
  session_type TEXT NOT NULL DEFAULT 'PARCIAL',      -- PARCIAL/FINAL

  -- 📅 FECHAS
  opened_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  closed_at TIMESTAMPTZ,

  -- 💵 MONTOS
  opening_balance NUMERIC(15,4) NOT NULL DEFAULT 0,  -- Efectivo inicial
  closing_balance NUMERIC(15,4),                     -- Efectivo final
  expected_balance NUMERIC(15,4),                    -- Balance esperado
  difference NUMERIC(15,4),                          -- Diferencia (±)

  -- 📊 RESUMEN POR MÉTODO
  cash_total NUMERIC(15,4) DEFAULT 0,
  card_total NUMERIC(15,4) DEFAULT 0,
  transfer_total NUMERIC(15,4) DEFAULT 0,
  digital_wallet_total NUMERIC(15,4) DEFAULT 0,
  other_total NUMERIC(15,4) DEFAULT 0,

  -- 📈 CONTADORES
  total_orders INT DEFAULT 0,
  total_payments INT DEFAULT 0,

  -- 🔐 ESTADO
  status TEXT NOT NULL DEFAULT 'ABIERTO',            -- ABIERTO/CERRADO

  -- 📝 NOTAS
  opening_notes TEXT,
  closing_notes TEXT,

  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);
```

**Tipos de Corte:**

- **PARCIAL**: Corte intermedio durante el día (ej: cambio de turno)
- **FINAL**: Corte definitivo al cierre del día

**Cálculo de Balance:**

```
expected_balance = opening_balance + cash_total
difference = closing_balance - expected_balance
```

## 🔧 Funciones RPC (Stored Procedures)

### 1. **register_payment** - Registrar un Pago

```sql
SELECT sales.register_payment(

  p_transaction_reference := NULL,
```

**Validaciones:**

- ✅ Monto es positivo
- ✅ Actualización atómica (transacción)

## 📊 Casos de Uso

### Caso 1: Pago Completo al Momento

```sql
-- 1. Employee crea orden
INSERT INTO sales.orders (
  id, shop_id, customer_id, employee_id,
  total_price, discount, igv, final_amount, remaining_balance
) VALUES (
  gen_random_uuid(), 'shop-uuid', 'customer-uuid', 'employee-uuid',
  250.00, 0, 45.00, 295.00, 295.00
);

-- 2. Cashier registra pago completo
SELECT sales.register_payment(
  p_order_id := 'order-uuid',
  p_amount := 295.00,
  p_payment_method := 'EFECTIVO',
  p_cash_register_session_id := 'session-uuid'
);

-- Resultado: payment_status = 'PAGADO', remaining_balance = 0
```

---

### Caso 2: Pago con Adelanto (2 pagos)

```sql
-- DÍA 1: Cliente paga 50% de adelanto
SELECT sales.register_payment(
  p_order_id := 'order-uuid',
  p_amount := 147.50,
  p_payment_method := 'EFECTIVO',
  p_cash_register_session_id := 'session-dia-1-uuid',
  p_notes := 'Adelanto 50%'
);
-- Resultado: payment_status = 'PARCIAL', remaining_balance = 147.50

-- DÍA 3: Cliente paga el saldo restante
SELECT sales.register_payment(
  p_order_id := 'order-uuid',
  p_amount := 147.50,
  p_payment_method := 'YAPE',
  p_cash_register_session_id := 'session-dia-3-uuid',
  p_transaction_reference := 'YAPE-OP-123456',
  p_notes := 'Pago final'
);
-- Resultado: payment_status = 'PAGADO', remaining_balance = 0
```

**Ventajas:**

- ✅ Cada pago se registra en la sesión de caja correspondiente
- ✅ El pago del día 3 aparece en el reporte del día 3
- ✅ Trazabilidad completa del historial de pagos
- ✅ Reconciliación diaria correcta

### Caso 4: Flujo Completo de Corte de Caja

```sql
-- 1. Abrir caja (8:00 AM)
SELECT sales.open_cash_register_session(
  p_shop_id := 'shop-uuid',
  p_cashier_id := 'cashier-uuid',
  p_opening_balance := 200.00,
  p_session_type := 'PARCIAL',
  p_opening_notes := 'Turno mañana'
);
-- session_id = 'session-1'

-- 2. Durante el turno: registrar pagos
SELECT sales.register_payment(..., p_cash_register_session_id := 'session-1');
SELECT sales.register_payment(..., p_cash_register_session_id := 'session-1');
-- ... más pagos

-- 3. Corte parcial (2:00 PM)
SELECT sales.close_cash_register_session(
  p_session_id := 'session-1',
  p_closing_balance := 1500.00,
  p_closing_notes := 'Cambio de turno'
);

-- 4. Abrir nueva sesión (2:00 PM)
SELECT sales.open_cash_register_session(
  p_shop_id := 'shop-uuid',
  p_cashier_id := 'otro-cashier-uuid',
  p_opening_balance := 1500.00,  -- balance del corte anterior
  p_session_type := 'FINAL',
  p_opening_notes := 'Turno tarde'
);
-- session_id = 'session-2'

-- 5. Más pagos durante la tarde
SELECT sales.register_payment(..., p_cash_register_session_id := 'session-2');

-- 6. Corte final del día (8:00 PM)
SELECT sales.close_cash_register_session(
  p_session_id := 'session-2',
  p_closing_balance := 2300.00,
  p_closing_notes := 'Cierre del día'
);
```

## 🔒 Seguridad y Validaciones

### A Nivel de Base de Datos

```sql
-- Constraints automáticos
CHECK (advance >= 0 AND advance <= final_amount)
CHECK (remaining_balance >= 0)
CHECK (discount >= 0 AND discount <= total_price)
CHECK (amount > 0)  -- en payments
```

```sql
-- Validaciones de negocio
```

## 📈 Queries de Reporte Útiles

### Reporte de Ventas por Método de Pago

```sql
SELECT
  payment_method,
  COUNT(*) AS num_payments,
  SUM(amount) AS total_amount,
  AVG(amount) AS avg_amount
FROM sales.payments
WHERE DATE(payment_date) = '2026-01-20'
GROUP BY payment_method
ORDER BY total_amount DESC;
```

### Órdenes con Pagos Pendientes > 7 Días

```sql
SELECT * FROM sales.get_pending_payment_orders()
WHERE days_pending > 7
ORDER BY days_pending DESC;
```

### Resumen de Sesiones de Caja del Mes

```sql
SELECT
  DATE(opened_at) AS fecha,
  COUNT(*) AS num_sesiones,
  SUM(cash_total + card_total + transfer_total + digital_wallet_total) AS total_vendido,
  SUM(difference) AS diferencia_total
FROM sales.cash_register_sessions
WHERE status = 'CERRADO'
  AND DATE_TRUNC('month', opened_at) = DATE_TRUNC('month', NOW())
GROUP BY DATE(opened_at)
ORDER BY fecha DESC;
```

### Top 10 Clientes por Compras

```sql
SELECT
  c.id,
  COALESCE(p.first_name || ' ' || p.last_name, p.legal_name) AS customer_name,
  COUNT(o.id) AS num_orders,
  SUM(o.final_amount) AS total_spent,
  SUM(o.remaining_balance) AS pending_balance
FROM sales.customers c
JOIN core.persons p ON c.person_id = p.id
JOIN sales.orders o ON o.customer_id = c.id
GROUP BY c.id, customer_name
ORDER BY total_spent DESC
LIMIT 10;
```
